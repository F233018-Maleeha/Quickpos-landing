# ⚡ QuickPOS Landing Page

A professional, pixel-perfect landing page for the QuickPOS point-of-sale system, built with PHP.

## Tech Stack
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Backend**: PHP 8+
- **Tools**: Jira, GitHub (GitFlow), Slack

## Setup Instructions

### Prerequisites
- PHP 8.0 or higher
- Web server (Apache/Nginx) OR PHP built-in server

### Run Locally

```bash
# Clone the repository
git clone https://github.com/F233018-Maleeha/Quickpos-landing
cd quickpos-landing

# Start PHP built-in server
php -S localhost:8000

# Visit in browser
open http://localhost:8000
```
